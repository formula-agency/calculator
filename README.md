# Калькулятор Формула

`index.html` публикуется через GitHub Pages. Ставки загружаются непосредственно из [публичной копии Google Таблицы](https://docs.google.com/spreadsheets/d/1kooRYR745pcOqj1SbIx3s1McN8I4CaoE5zAcLRuIibQ/edit?gid=1500037557), с листа `Актуальный (расширенный)`. Строки, в которых столбец B содержит `приостановлено`, не участвуют в расчётах. Локальный файл ставок, сервисный аккаунт и Cloud Run не нужны.

Для работы калькулятора оставьте у копии таблицы доступ на чтение для всех, у кого есть ссылка. Этот доступ распространяется **на всю копию**, включая другие листы, а не только на лист со ставками. Если в ней есть закрытые данные, их нужно убрать из публичной копии или использовать серверный способ загрузки.

Чтобы проверить данные, откройте `index.html` или опубликованный сайт. Над калькуляторами появится название листа и число загруженных ставок. Кнопка обновления перечитывает таблицу. Изменения оригинальной таблицы не попадут в копию автоматически, если вы не настроили их синхронизацию.

После проверки локальной версии опубликуйте `index.html`, `calculator_rates.js` и `README.md` в репозитории GitHub Pages.
