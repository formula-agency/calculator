# Калькулятор Формула КЦ

Статическая версия калькулятора для публикации через GitHub Pages.

## Что публиковать

- `index.html`
- `mortgage_calculator_data.js`

Файл `mortgage_calculator_no_assortment.html` оставлен как совместимый редирект на `index.html`.

## Публикация через GitHub Pages

1. Загрузите содержимое этой папки в GitHub-репозиторий.
2. Откройте `Settings` -> `Pages`.
3. Включите публикацию из ветки `main` и корня репозитория (`/root`).
4. Дождитесь ссылки вида `https://<user>.github.io/<repo>/`.

## Локальная проверка

Для локального запуска используйте любой статический сервер, например:

```powershell
python -m http.server 8080
```
